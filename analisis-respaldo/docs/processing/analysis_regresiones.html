Qué se hace y por qué

Qué se hace

Este documento estima regresiones que agrupan las olas de la Encuesta CEP y comparan, dentro de cada ola, a quienes cursaron la asignatura de Educación Ciudadana con quienes no la cursaron. Para el interés político se usan modelos lineales sobre la escala de 1 (nada interesado) a 5 (muy interesado); para el voto en la 2ª vuelta presidencial de 2021 se usan modelos logísticos. En ambos casos se estiman tres modelos que agregan controles de forma progresiva, todos con efectos fijos de ola:

  1. Solo efectos fijos de ola, que hacen que la comparación se realice dentro de cada ola.
  2. Con un control socioeconómico: el nivel educacional o el grupo socioeconómico del hogar.
  3. Con el control socioeconómico y la edad.

A partir de estos modelos se estiman variantes: el grupo socioeconómico en lugar del nivel educacional, interacciones entre la asignatura y el grupo socioeconómico, distintas agrupaciones del grupo socioeconómico, muestras restringidas a jóvenes, la exclusión de la CEP 85 y todas las combinaciones de control, imputación de fechas de nacimiento y ponderación.

Por qué se hace

Las regresiones son el primer paso del análisis: cuantifican la asociación entre haber cursado la asignatura y cada resultado, y muestran cuánto depende de los controles. Su principal limitación es que el tratamiento se asigna por la fecha de nacimiento, por lo que todas las personas que cursaron la asignatura tienen entre 18 y 23 años. La comparación con el resto de la muestra mezcla el efecto de la asignatura con diferencias de edad y de cohorte, que un control lineal de edad puede no capturar completamente. Por eso sus coeficientes se interpretan como asociaciones, y los diseños de diferencia en diferencias de las otras pestañas buscan aislar el efecto.

La elección de controles también importa. Para quienes todavía estudian, el nivel educacional es la etapa en que se encuentran y puede ser afectado por el tratamiento, por lo que controlar por él puede sesgar la estimación. El grupo socioeconómico describe al hogar y difícilmente es afectado por la asignatura, por lo que se usa como alternativa. Las variantes permiten evaluar si las conclusiones dependen de estas decisiones. Al comparar muchas especificaciones es esperable que alguna tenga un valor p bajo 0,05 aunque no haya efecto, por lo que ninguna debe elegirse por su significancia.

agrupar_gse <- function(x) {
  factor(dplyr::case_when(x %in% c("ABC1", "C2") ~ "ABC1-C2",
                          x == "C3" ~ "C3",
                          x %in% c("D", "E") ~ "D-E"),
         levels = c("D-E", "C3", "ABC1-C2"))
}

Interés político

La base de interés político reúne las olas CEP 85, 88, 92, 93, 95 y 96, que incluyen la pregunta “¿Cuán interesado está Ud. en la política?”. La escala se invirtió para que 1 indique nada interesado y 5 muy interesado. Cuando no hay fecha de nacimiento, se imputa desde la edad declarada (ver preparation.qmd).

Sensibilidad a la agrupación del grupo socioeconómico

Para cada agrupación del grupo socioeconómico se estima el modelo con el control (2) y con el control y la edad (3).

Código 
## Agrupaciones --------------------------------------------------------------
agrupaciones <- list(
  "a) 5 categorías (ABC1, C2, C3, D, E)" = function(x) x,
  "b) 3: ABC1-C2, C3, D-E (principal)"   = agrupar_gse,
  "c) 2: ABC1-C2 vs resto"               = function(x) factor(x %in% c("ABC1", "C2")),
  "d) 2: D-E vs resto"                   = function(x) factor(x %in% c("D", "E")),
  "e) continua (1 = ABC1 a 5 = E)"       = function(x) as.integer(x)
)

# Coeficiente de educacion_ciudadana en una especificación
coef_trat <- function(m) {
  s <- summary(m)$coefficients["educacion_ciudadana", ]
  data.frame(estimacion = s[1], ee = s[2], p = s[4], n = nobs(m))
}

sensibilidad_interes <- dplyr::bind_rows(lapply(names(agrupaciones), function(k) {
  di <- int_gse %>% dplyr::mutate(g_ = agrupaciones[[k]](gse))
  dplyr::bind_rows(
    cbind(agrupacion = k, resultado = "Interés", modelo = "2: + gse",
          coef_trat(lm(int_pol ~ educacion_ciudadana + g_ + factor(ola), data = di))),
    cbind(agrupacion = k, resultado = "Interés", modelo = "3: + gse y edad",
          coef_trat(lm(int_pol ~ educacion_ciudadana + g_ + edad_nac + factor(ola), data = di)))
  )
}))

Muestras de jóvenes

Al restringir la edad, el grupo de comparación queda más cerca en edad de quienes cursaron la asignatura. Se estiman cinco modelos sobre la misma muestra de casos completos, con menores de 30 años y con menores de 35 años según edad_nac: solo efectos fijos de ola (1), con nivel educacional (2), con nivel educacional y edad (3), con grupo socioeconómico (4) y con grupo socioeconómico y edad (5).

## Muestras y modelos --------------------------------------------------------
muestra_edad <- function(edad_limite) {
  data_int %>%
    dplyr::filter(edad_nac < edad_limite) %>%
    dplyr::select(ola, int_pol, educacion_ciudadana, educ, gse3, edad_nac) %>%
    na.omit()
}

estimar_modelos <- function(d) {

Combinaciones de especificaciones

Las regresiones se reestiman con todas las combinaciones de tres decisiones: el control socioeconómico (nivel educacional o grupo socioeconómico), el tratamiento de los casos sin fecha de nacimiento (imputarlos desde la edad declarada o excluirlos) y el uso del ponderador de la encuesta (pond). En cada combinación se estiman los mismos tres modelos sobre la misma muestra de casos completos.

  • Imputación. La versión sin imputación excluye los casos de las olas 85, 92 y 93 cuya fecha de nacimiento se imputó desde la edad declarada. La CEP 96 se mantiene en ambas versiones, porque no tiene fecha de nacimiento para ningún caso.
  • Ponderación. El ponderador de cada ola suma el número de casos de la ola.

Todas las combinaciones usan errores estándar robustos HC1, porque los errores clásicos no son válidos con ponderadores.

combinaciones <- expand.grid(

  stringsAsFactors = FALSE

# Tres modelos de una combinación, sobre la misma muestra de casos completos
estimar_combinacion <- function(control, imputacion, ponderacion) {
  var_control <- if (control == "Nivel educacional") "educ" else "gse3"
  d <- data_int
  if (imputacion == "Sin imputación") {
    d <- d %>% dplyr::filter(!fecha_nac_imputada | ola == "96")
  }
  d <- d %>%
    dplyr::select(ola, int_pol, educacion_ciudadana, dplyr::all_of(var_control),
                  edad_nac, pond) %>%
    na.omit() %>%
    dplyr::mutate(peso = if (ponderacion == "Ponderado") pond else 1)
  formulas <- list(
    int_pol ~ educacion_ciudadana + factor(ola),
    as.formula(paste("int_pol ~ educacion_ciudadana +", var_control, "+ factor(ola)")),
    as.formula(paste("int_pol ~ educacion_ciudadana +", var_control, "+ edad_nac + factor(ola)"))
  )
  lapply(formulas, function(f) lm(f, data = d, weights = peso))
}

modelos_combinaciones <- lapply(seq_len(nrow(combinaciones)), function(i) {
  estimar_combinacion(combinaciones$control[i], combinaciones$imputacion[i],
                      combinaciones$ponderacion[i])
})

# Qué se hace y por qué

## Qué se hace

Este documento estima regresiones que agrupan las olas de la Encuesta CEP y comparan, dentro de cada ola, a quienes cursaron la asignatura de Educación Ciudadana con quienes no la cursaron. Para el interés político se usan modelos lineales sobre la escala de 1 (nada interesado) a 5 (muy interesado); para el voto en la 2ª vuelta presidencial de 2021 se usan modelos logísticos. En ambos casos se estiman tres modelos que agregan controles de forma progresiva, todos con efectos fijos de ola:

1. Solo efectos fijos de ola, que hacen que la comparación se realice dentro de cada ola.
2. Con un control socioeconómico: el nivel educacional o el grupo socioeconómico del hogar.
3. Con el control socioeconómico y la edad.

A partir de estos modelos se estiman variantes: el grupo socioeconómico en lugar del nivel educacional, interacciones entre la asignatura y el grupo socioeconómico, distintas agrupaciones del grupo socioeconómico, muestras restringidas a jóvenes, la exclusión de la CEP 85 y todas las combinaciones de control, imputación de fechas de nacimiento y ponderación.

## Por qué se hace

Las regresiones son el primer paso del análisis: cuantifican la asociación entre haber cursado la asignatura y cada resultado, y muestran cuánto depende de los controles. Su principal limitación es que el tratamiento se asigna por la fecha de nacimiento, por lo que todas las personas que cursaron la asignatura tienen entre 18 y 23 años. La comparación con el resto de la muestra mezcla el efecto de la asignatura con diferencias de edad y de cohorte, que un control lineal de edad puede no capturar completamente. Por eso sus coeficientes se interpretan como asociaciones, y los diseños de diferencia en diferencias de las otras pestañas buscan aislar el efecto.

La elección de controles también importa. Para quienes todavía estudian, el nivel educacional es la etapa en que se encuentran y puede ser afectado por el tratamiento, por lo que controlar por él puede sesgar la estimación. El grupo socioeconómico describe al hogar y difícilmente es afectado por la asignatura, por lo que se usa como alternativa. Las variantes permiten evaluar si las conclusiones dependen de estas decisiones. Al comparar muchas especificaciones es esperable que alguna tenga un valor p bajo 0,05 aunque no haya efecto, por lo que ninguna debe elegirse por su significancia.

## Combinaciones de especificaciones

Las regresiones se reestiman con todas las combinaciones de tres decisiones: el control socioeconómico (nivel educacional o grupo socioeconómico), el tratamiento de los casos sin fecha de nacimiento (imputarlos desde la edad declarada o excluirlos) y el uso del ponderador de la encuesta (`pond`). En cada combinación se estiman los mismos tres modelos sobre la misma muestra de casos completos.

- **Imputación.** La versión sin imputación excluye los casos de las olas 85, 92 y 93 cuya fecha de nacimiento se imputó desde la edad declarada. La CEP 96 se mantiene en ambas versiones, porque no tiene fecha de nacimiento para ningún caso.
- **Ponderación.** El ponderador de cada ola suma el número de casos de la ola.

Todas las combinaciones usan errores estándar robustos HC1, porque los errores clásicos no son válidos con ponderadores.

```{r}

combinaciones <- expand.grid(
  control     = c("Nivel educacional", "Grupo socioeconómico"),

  stringsAsFactors = FALSE

# Tres modelos de una combinación, sobre la misma muestra de casos completos
estimar_combinacion <- function(control, imputacion, ponderacion) {
  var_control <- if (control == "Nivel educacional") "educ" else "gse3"
  d <- data_int
  if (imputacion == "Sin imputación") {
    d <- d %>% dplyr::filter(!fecha_nac_imputada | ola == "96")
  }
  d <- d %>%
    dplyr::select(ola, int_pol, educacion_ciudadana, dplyr::all_of(var_control),
                  edad_nac, pond) %>%
    na.omit() %>%
    dplyr::mutate(peso = if (ponderacion == "Ponderado") pond else 1)
  formulas <- list(
    int_pol ~ educacion_ciudadana + factor(ola),
    as.formula(paste("int_pol ~ educacion_ciudadana +", var_control, "+ factor(ola)")),
    as.formula(paste("int_pol ~ educacion_ciudadana +", var_control, "+ edad_nac + factor(ola)"))
  )
  lapply(formulas, function(f) lm(f, data = d, weights = peso))
}
```

## Interpretación

Quienes cursaron la asignatura y podían votar tenían 18 años en diciembre de 2021, por lo que en esta elección eran los votantes más jóvenes de la muestra. La edad incluida de forma lineal puede no capturar completamente las diferencias de participación en esas edades. Como la pregunta de voto se refiere a una sola elección, no es posible aplicar los diseños de diferencia en diferencias de las otras pestañas, por lo que para el voto el análisis se limita a estas regresiones y sus coeficientes no pueden interpretarse como efectos de la asignatura.
