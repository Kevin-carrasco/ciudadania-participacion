Qué se hace y por qué

Qué se hace

Este documento reestima los principales análisis de interés político (regresiones, diferencia en diferencias 2x2 y diferencia en diferencias escalonada) en tres versiones: sin ponderar, ponderada con el ponderador de la Encuesta CEP (pond) y considerando el diseño muestral. Cada especificación se estima sobre la misma muestra en las tres versiones, y la tabla final compara el estimador del tratamiento. Las versiones sin ponderar y ponderada usan errores estándar robustos HC1, por lo que los errores de la columna sin ponderar pueden diferir levemente de los reportados en los otros documentos.

Por qué se hace

Los análisis principales se estiman sin ponderar, lo que da más precisión pero supone que la muestra representa bien a la población en las variables relevantes. Los jóvenes están subrepresentados en la Encuesta CEP y reciben ponderadores mayores que el promedio, por lo que ponderar aumenta su peso en las estimaciones. Si los resultados cambiaran al ponderar, la composición de la muestra estaría afectando las conclusiones. Considerar el diseño muestral permite además evaluar si los errores estándar cambian al tomar en cuenta la estratificación.

El ponderador de cada ola suma el número de casos de la ola, de modo que las olas agrupadas conservan su peso relativo. Carga los datos procesados en preparation.qmd. La tabla de comparación se guarda en output/tables/ponderado_comparacion.html y los resultados en output/models/modelos_ponderados.rds.

Además de la versión ponderada con errores HC1, cada especificación se estima considerando el diseño muestral con survey::svydesign(ids = ~1, strata = ~interaction(ola, estrato), weights = ~pond) y survey::svyglm. El estrato se combina con la ola porque cada ola es una muestra independiente y porque en la CEP 85 el estrato se define de otra forma. Las bases no traen identificadores de conglomerado, por lo que el diseño trata a cada persona como unidad primaria de muestreo; si la muestra se seleccionó por conglomerados, estos errores pueden subestimar la incertidumbre. El diseño se define sobre la muestra de cada especificación, y los estratos con una sola observación se tratan con options(survey.lonely.psu = "adjust").

Las muestras, especificaciones y definiciones de tratamiento son las mismas de los documentos de regresiones, diferencia en diferencias 2x2 y diferencia en diferencias escalonada. Las regresiones que agrupan olas incluyen efectos fijos de ola, igual que en esos documentos.

Código 
# Matriz de varianzas robusta HC1
vc <- function(m) sandwich::vcovHC(m, type = "HC1")

# Coeficiente con error estándar HC1
coef_hc1 <- function(m, v) {
  s <- lmtest::coeftest(m, vcov. = vc(m))[v, ]
  c(estimacion = unname(s[1]), ee = unname(s[2]), p = unname(s[4]))
}

# Diseño muestral de una muestra de análisis (sin conglomerados)
diseno <- function(datos) {
  survey::svydesign(ids = ~1, strata = ~interaction(ola, estrato), weights = ~pond,
                    data = datos)
}

# Coeficiente de un modelo svyglm (errores del diseño)
coef_svy <- function(m, v) {
  s <- summary(m)$coefficients[v, ]
  c(estimacion = unname(s[1]), ee = unname(s[2]), p = unname(s[4]))
}

# Estima un modelo lineal sin ponderar, ponderado y con diseño muestral, y
# devuelve el coeficiente v de cada versión
comparar_lm <- function(analisis, modelo, formula, datos, v) {
  m0 <- lm(formula, data = datos)
  m1 <- lm(formula, data = datos, weights = pond)
  m2 <- survey::svyglm(formula, design = diseno(datos))
  a <- coef_hc1(m0, v); b <- coef_hc1(m1, v); d <- coef_svy(m2, v)
  data.frame(analisis, modelo, n = nobs(m0),
             sin_ponderar = a["estimacion"], ee_sin = a["ee"], p_sin = a["p"],
             ponderado = b["estimacion"], ee_pond = b["ee"], p_pond = b["p"],
             ee_diseno = d["ee"], p_diseno = d["p"])
}

Diferencia en diferencias escalonada

La estructura del diseño (cohortes de adopción g, tratamiento W y celdas mixtas) se define igual que en el documento principal, con proporciones de tratados sin ponderar, para que la comparación refleje solo el efecto de ponderar la estimación. El ATT agregado de M2 pondera los efectos de celda por la suma de ponderadores de cada celda en la versión ponderada y por su número de casos en la versión sin ponderar. Los efectos parciales promedio sobre los tratados de los modelos no lineales se promedian con el ponderador en las versiones ponderada y con diseño muestral. La versión con diseño muestral comparte las estimaciones puntuales de la versión ponderada y solo cambia sus errores estándar. El logit binario se estima por cuasi verosimilitud, que entrega los mismos coeficientes que el logit y admite ponderadores no enteros.

## Funciones -----------------------------------------------------------------
# ATT agregado de M2: combinación lineal de efectos de celda. V es la matriz
# de varianzas del modelo (HC1 para lm, la del diseño para svyglm)
att_m2 <- function(m, pesos, V = vc(m)) {
  coefs <- paste0("W:", celdas_tr$nombre)
  w <- pesos / sum(pesos)
  est <- sum(w * coef(m)[coefs])
  ee <- sqrt(as.numeric(t(w) %*% V[coefs, coefs] %*% w))
  c(estimacion = est, ee = ee, p = 2 * pnorm(-abs(est / ee)))
}

# Efecto parcial promedio de W sobre los tratados. Para svyglm se usa la
# matriz de varianzas del diseño (vcov = TRUE)
ape_w <- function(m, datos, ponderar, vcov = "HC1") {
  a <- marginaleffects::avg_comparisons(
    m, variables = list(W = c(0, 1)), newdata = subset(datos, W == 1),
    wts = if (ponderar) "pond" else FALSE, vcov = vcov)
  c(estimacion = a$estimate, ee = a$std.error, p = a$p.value)
}

fila <- function(modelo, n, a, b, d) {
  data.frame(analisis = "DiD escalonado", modelo, n,
             sin_ponderar = a["estimacion"], ee_sin = a["ee"], p_sin = a["p"],
             ponderado = b["estimacion"], ee_pond = b["ee"], p_pond = b["p"],
             ee_diseno = d["ee"], p_diseno = d["p"])
}

Voto

Esta comparación se realizó solo para interés político. Los diseños de diferencia en diferencias no pueden aplicarse al voto, porque su pregunta se refiere a una sola elección, y las regresiones de voto se estiman sin ponderar en el documento de regresiones. Reestimar esas regresiones con ponderadores y con el diseño muestral es posible y queda pendiente.

# Qué se hace y por qué

## Qué se hace

Este documento reestima los principales análisis de interés político (regresiones, diferencia en diferencias 2x2 y diferencia en diferencias escalonada) en tres versiones: sin ponderar, ponderada con el ponderador de la Encuesta CEP (`pond`) y considerando el diseño muestral. Cada especificación se estima sobre la misma muestra en las tres versiones, y la tabla final compara el estimador del tratamiento. Las versiones sin ponderar y ponderada usan errores estándar robustos HC1, por lo que los errores de la columna sin ponderar pueden diferir levemente de los reportados en los otros documentos.

## Por qué se hace

Los análisis principales se estiman sin ponderar, lo que da más precisión pero supone que la muestra representa bien a la población en las variables relevantes. Los jóvenes están subrepresentados en la Encuesta CEP y reciben ponderadores mayores que el promedio, por lo que ponderar aumenta su peso en las estimaciones. Si los resultados cambiaran al ponderar, la composición de la muestra estaría afectando las conclusiones. Considerar el diseño muestral permite además evaluar si los errores estándar cambian al tomar en cuenta la estratificación.

El ponderador de cada ola suma el número de casos de la ola, de modo que las olas agrupadas conservan su peso relativo. Carga los datos procesados en `preparation.qmd`. La tabla de comparación se guarda en `output/tables/ponderado_comparacion.html` y los resultados en `output/models/modelos_ponderados.rds`.

Además de la versión ponderada con errores HC1, cada especificación se estima considerando el diseño muestral con `survey::svydesign(ids = ~1, strata = ~interaction(ola, estrato), weights = ~pond)` y `survey::svyglm`. El estrato se combina con la ola porque cada ola es una muestra independiente y porque en la CEP 85 el estrato se define de otra forma. Las bases no traen identificadores de conglomerado, por lo que el diseño trata a cada persona como unidad primaria de muestreo; si la muestra se seleccionó por conglomerados, estos errores pueden subestimar la incertidumbre. El diseño se define sobre la muestra de cada especificación, y los estratos con una sola observación se tratan con `options(survey.lonely.psu = "adjust")`.

Las muestras, especificaciones y definiciones de tratamiento son las mismas de los documentos de regresiones, diferencia en diferencias 2x2 y diferencia en diferencias escalonada. Las regresiones que agrupan olas incluyen efectos fijos de ola, igual que en esos documentos.

# Funciones auxiliares

```{r}
# Matriz de varianzas robusta HC1
vc <- function(m) sandwich::vcovHC(m, type = "HC1")

# Coeficiente con error estándar HC1
coef_hc1 <- function(m, v) {
  s <- lmtest::coeftest(m, vcov. = vc(m))[v, ]
  c(estimacion = unname(s[1]), ee = unname(s[2]), p = unname(s[4]))
}

# Diseño muestral de una muestra de análisis (sin conglomerados)
diseno <- function(datos) {
  survey::svydesign(ids = ~1, strata = ~interaction(ola, estrato), weights = ~pond,
                    data = datos)
}

# Coeficiente de un modelo svyglm (errores del diseño)
coef_svy <- function(m, v) {
  s <- summary(m)$coefficients[v, ]
  c(estimacion = unname(s[1]), ee = unname(s[2]), p = unname(s[4]))
}

# Estima un modelo lineal sin ponderar, ponderado y con diseño muestral, y
# devuelve el coeficiente v de cada versión
comparar_lm <- function(analisis, modelo, formula, datos, v) {
  m0 <- lm(formula, data = datos)
  m1 <- lm(formula, data = datos, weights = pond)
  m2 <- survey::svyglm(formula, design = diseno(datos))
  a <- coef_hc1(m0, v); b <- coef_hc1(m1, v); d <- coef_svy(m2, v)
  data.frame(analisis, modelo, n = nobs(m0),
             sin_ponderar = a["estimacion"], ee_sin = a["ee"], p_sin = a["p"],
             ponderado = b["estimacion"], ee_pond = b["ee"], p_pond = b["p"],
             ee_diseno = d["ee"], p_diseno = d["p"])
}

resultados <- list()
agregar <- function(x) resultados[[length(resultados) + 1]] <<- x
```

## Diferencia en diferencias escalonada

La estructura del diseño (cohortes de adopción `g`, tratamiento `W` y celdas mixtas) se define igual que en el documento principal, con proporciones de tratados sin ponderar, para que la comparación refleje solo el efecto de ponderar la estimación. El ATT agregado de M2 pondera los efectos de celda por la suma de ponderadores de cada celda en la versión ponderada y por su número de casos en la versión sin ponderar. Los efectos parciales promedio sobre los tratados de los modelos no lineales se promedian con el ponderador en las versiones ponderada y con diseño muestral. La versión con diseño muestral comparte las estimaciones puntuales de la versión ponderada y solo cambia sus errores estándar. El logit binario se estima por cuasi verosimilitud, que entrega los mismos coeficientes que el logit y admite ponderadores no enteros.

```{r}
## Estructura ----------------------------------------------------------------
did <- did_int %>%
  dplyr::mutate(
    ola_num = as.numeric(as.character(ola)),
    cohorte_4m = as.integer(format(fecha_nac, "%Y")) +
      dplyr::if_else(as.integer(format(fecha_nac, "%m")) >= 4, 18L, 17L),
    dosis_plan = pmax(0L, cohorte_4m - 2015L)
  )

celdas <- did %>%
  dplyr::group_by(edad_nac, ola_num) %>%
  dplyr::summarise(n = dplyr::n(), suma_pond = sum(pond),
                   prop_trat = mean(educacion_ciudadana), .groups = "drop")

cohortes <- celdas %>%
  dplyr::group_by(edad_nac) %>%
  dplyr::summarise(g = if (any(prop_trat >= 0.5)) min(ola_num[prop_trat >= 0.5]) else 0)

celdas <- celdas %>%
  dplyr::left_join(cohortes, by = "edad_nac") %>%
  dplyr::mutate(W = as.integer(g > 0 & ola_num >= g),
                mixta = prop_trat >= 0.1 & prop_trat <= 0.9)

primera_ola <- min(did$ola_num)

d_est <- did %>%
  dplyr::left_join(cohortes, by = "edad_nac") %>%
  dplyr::filter(g != primera_ola) %>%
  dplyr::mutate(W = as.integer(g > 0 & ola_num >= g),
                y01 = (int_pol - 1) / 4,
                int_alto = as.integer(int_pol >= 3))

celdas_tr <- celdas %>%
  dplyr::filter(W == 1, g != primera_ola) %>%
  dplyr::mutate(nombre = paste0("c_", edad_nac, "_", ola_num))
for (i in seq_len(nrow(celdas_tr))) {
  d_est[[celdas_tr$nombre[i]]] <- as.integer(d_est$edad_nac == celdas_tr$edad_nac[i] &
                                               d_est$ola_num == celdas_tr$ola_num[i])
}

efectos_fijos <- "factor(edad_nac) + factor(ola_num)"
f_m1 <- function(y) as.formula(paste(y, "~ W +", efectos_fijos))
f_m2 <- function(y) as.formula(paste0(y, " ~ W:(", paste(celdas_tr$nombre, collapse = " + "),
                                     ") + ", efectos_fijos))

## Funciones -----------------------------------------------------------------
# ATT agregado de M2: combinación lineal de efectos de celda. V es la matriz
# de varianzas del modelo (HC1 para lm, la del diseño para svyglm)
att_m2 <- function(m, pesos, V = vc(m)) {
  coefs <- paste0("W:", celdas_tr$nombre)
  w <- pesos / sum(pesos)
  est <- sum(w * coef(m)[coefs])
  ee <- sqrt(as.numeric(t(w) %*% V[coefs, coefs] %*% w))
  c(estimacion = est, ee = ee, p = 2 * pnorm(-abs(est / ee)))
}

# Efecto parcial promedio de W sobre los tratados. Para svyglm se usa la
# matriz de varianzas del diseño (vcov = TRUE)
ape_w <- function(m, datos, ponderar, vcov = "HC1") {
  a <- marginaleffects::avg_comparisons(
    m, variables = list(W = c(0, 1)), newdata = subset(datos, W == 1),
    wts = if (ponderar) "pond" else FALSE, vcov = vcov)
  c(estimacion = a$estimate, ee = a$std.error, p = a$p.value)
}

fila <- function(modelo, n, a, b, d) {
  data.frame(analisis = "DiD escalonado", modelo, n,
             sin_ponderar = a["estimacion"], ee_sin = a["ee"], p_sin = a["p"],
             ponderado = b["estimacion"], ee_pond = b["ee"], p_pond = b["p"],
             ee_diseno = d["ee"], p_diseno = d["p"])
}

diseno_est <- diseno(d_est)

## M1 y M2 lineales ----------------------------------------------------------
agregar(comparar_lm("DiD escalonado", "M1 lineal", f_m1("int_pol"), d_est, "W"))

m2_0 <- lm(f_m2("int_pol"), data = d_est)
m2_1 <- lm(f_m2("int_pol"), data = d_est, weights = pond)
m2_s <- survey::svyglm(f_m2("int_pol"), design = diseno_est)
agregar(fila("M2 lineal (ATT)", nrow(d_est), att_m2(m2_0, celdas_tr$n),
             att_m2(m2_1, celdas_tr$suma_pond),
             att_m2(m2_s, celdas_tr$suma_pond, V = vcov(m2_s))))

## Modelos no lineales (efecto parcial promedio de W) ------------------------
for (esp in list(list("M1 logit fraccional (APE)", f_m1("y01")),
                 list("M2 logit fraccional (APE)", f_m2("y01")),
                 list("M1 logit binario (APE)", f_m1("int_alto")),
                 list("M2 logit binario (APE)", f_m2("int_alto")))) {
  g0 <- glm(esp[[2]], family = quasibinomial(link = "logit"), data = d_est)
  g1 <- glm(esp[[2]], family = quasibinomial(link = "logit"), data = d_est, weights = pond)
  gs <- survey::svyglm(esp[[2]], design = diseno_est, family = quasibinomial(link = "logit"))
  agregar(fila(esp[[1]], nrow(d_est), ape_w(g0, d_est, FALSE), ape_w(g1, d_est, TRUE),
               ape_w(gs, d_est, TRUE, vcov = TRUE)))
}

## Robustez ------------------------------------------------------------------
mixtas <- celdas %>% dplyr::filter(mixta) %>% dplyr::select(edad_nac, ola_num)
d_sin_mixtas <- d_est %>% dplyr::anti_join(mixtas, by = c("edad_nac", "ola_num"))
agregar(comparar_lm("DiD escalonado", "M1 lineal sin celdas mixtas", f_m1("int_pol"), d_sin_mixtas, "W"))

d_sinplan <- d_est %>% dplyr::filter(g > 0 | dosis_plan == 0)
agregar(comparar_lm("DiD escalonado", "M1 lineal, controles sin Plan", f_m1("int_pol"), d_sinplan, "W"))

## Adelantos -----------------------------------------------------------------
olas <- sort(unique(d_est$ola_num))
adelantos <- cohortes %>%
  dplyr::filter(g > 0, g != primera_ola) %>%
  dplyr::rowwise() %>%
  dplyr::reframe(edad_nac = edad_nac, g = g, ola_num = head(olas[olas < g], -1)) %>%
  dplyr::mutate(nombre = paste0("lead_", edad_nac, "_", ola_num))
for (i in seq_len(nrow(adelantos))) {
  d_est[[adelantos$nombre[i]]] <- as.integer(d_est$edad_nac == adelantos$edad_nac[i] &
                                               d_est$ola_num == adelantos$ola_num[i])
}
f_ad <- as.formula(paste("int_pol ~ W +", paste(adelantos$nombre, collapse = " + "), "+", efectos_fijos))

prueba_adelantos <- function(w) {
  base <- if (w) lm(f_m1("int_pol"), data = d_est, weights = pond) else lm(f_m1("int_pol"), data = d_est)
  ad <- if (w) lm(f_ad, data = d_est, weights = pond) else lm(f_ad, data = d_est)
  lmtest::waldtest(base, ad, vcov = vc(ad), test = "F")$`Pr(>F)`[2]
}
# Con diseño muestral: prueba de Wald conjunta de los adelantos
m_ad_s <- survey::svyglm(f_ad, design = diseno(d_est))
prueba_ad_s <- survey::regTermTest(m_ad_s, as.formula(paste("~", paste(adelantos$nombre, collapse = " + "))))

pruebas_adelantos <- c(sin_ponderar = prueba_adelantos(FALSE), ponderado = prueba_adelantos(TRUE),
                       diseno = as.numeric(prueba_ad_s$p))
pruebas_adelantos
```

# Voto

Esta comparación se realizó solo para interés político. Los diseños de diferencia en diferencias no pueden aplicarse al voto, porque su pregunta se refiere a una sola elección, y las regresiones de voto se estiman sin ponderar en el documento de regresiones. Reestimar esas regresiones con ponderadores y con el diseño muestral es posible y queda pendiente.
