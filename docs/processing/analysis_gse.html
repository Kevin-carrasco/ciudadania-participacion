Este documento replica los análisis de regresión de analysis.qmd que usan el nivel educacional como control, reemplazándolo por el grupo socioeconómico (gse). Carga los datos procesados en preparation.qmd. Las tablas se guardan en output/tables/gse_*.html, y las muestras y modelos en output/models/modelos_gse.rds.

A diferencia del nivel educacional, que para quienes siguen estudiando es un resultado posterior al tratamiento, el grupo socioeconómico describe al hogar y difícilmente es afectado por la asignatura. La agrupación principal es ABC1-C2, C3 y D-E, con D-E como categoría de referencia, porque el grupo E tiene muy pocos casos en todas las olas. Los análisis de diferencia en diferencias no usan el nivel educacional y no se replican aquí.

Se reportan todas las especificaciones estimadas. Al comparar muchas especificaciones, es esperable que alguna tenga un valor p bajo 0,05 aunque no haya efecto, por lo que ninguna debe elegirse por su significancia.

Sensibilidad a la agrupación del grupo socioeconómico

Replica la comparación de agrupaciones del nivel educacional. Para cada agrupación de gse se estima el modelo con el control (2) y con el control y la edad (3), en interés político y en voto.

Código 
## Agrupaciones --------------------------------------------------------------
agrupaciones <- list(
  "a) 5 categorías (ABC1, C2, C3, D, E)" = function(x) x,
  "b) 3: ABC1-C2, C3, D-E (principal)"   = agrupar_gse,
  "c) 2: ABC1-C2 vs resto"               = function(x) factor(x %in% c("ABC1", "C2")),
  "d) 2: D-E vs resto"                   = function(x) factor(x %in% c("D", "E")),
  "e) continua (1 = ABC1 a 5 = E)"       = function(x) as.integer(x)
)

# Coeficiente de educacion_ciudadana en una especificación
coef_trat <- function(m) {
  s <- summary(m)$coefficients["educacion_ciudadana", ]
  data.frame(estimacion = s[1], ee = s[2], p = s[4], n = nobs(m))
}

sensibilidad_gse <- dplyr::bind_rows(lapply(names(agrupaciones), function(k) {
  di <- int_gse %>% dplyr::mutate(g_ = agrupaciones[[k]](gse))
  dv <- voto_gse %>% dplyr::mutate(g_ = agrupaciones[[k]](gse))
  dplyr::bind_rows(
    cbind(agrupacion = k, resultado = "Interés", modelo = "2: + gse",
          coef_trat(lm(int_pol ~ educacion_ciudadana + g_, data = di))),
    cbind(agrupacion = k, resultado = "Interés", modelo = "3: + gse y edad",
          coef_trat(lm(int_pol ~ educacion_ciudadana + g_ + edad_nac, data = di))),
    cbind(agrupacion = k, resultado = "Voto (logit)", modelo = "2: + gse",
          coef_trat(glm(voto ~ educacion_ciudadana + g_, family = binomial, data = dv))),
    cbind(agrupacion = k, resultado = "Voto (logit)", modelo = "3: + gse y edad",
          coef_trat(glm(voto ~ educacion_ciudadana + g_ + edad_nac, family = binomial, data = dv)))
  )
}))

          coef_trat(glm(voto ~ educacion_ciudadana + g_, family = binomial, data = dv))),
    cbind(agrupacion = k, resultado = "Voto (logit)", modelo = "3: + gse y edad",
          coef_trat(glm(voto ~ educacion_ciudadana + g_ + edad_nac, family = binomial, data = dv)))
  )
}))
