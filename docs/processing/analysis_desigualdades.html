Qué se hace y por qué

Qué se hace

Este documento estima el efecto de la asignatura de Educación Ciudadana sobre cuatro medidas de la distribución del interés político, la confianza política y el voto en la 2ª vuelta presidencial de 2021: el nivel (la media o la proporción), la dispersión (la desviación estándar), la brecha social (la diferencia entre personas de origen social alto y bajo) y la insuficiencia (la proporción bajo un umbral mínimo). Cada medida se calcula en celdas de ola y grupo de edad, y el efecto se estima con una diferencia en diferencias sobre esas medidas, siguiendo los diseños de la pestaña Diferencia en diferencias. Las estimaciones se complementan con chequeos de regresión individual, pruebas de robustez, un placebo con olas previas a la asignatura y una comparación descriptiva con emparejamiento por puntaje de propensión.

Por qué se hace

Los análisis anteriores evalúan si la asignatura cambió el promedio de cada resultado. Una política educativa puede, sin embargo, afectar la distribución sin mover el promedio, por ejemplo reduciendo la distancia entre jóvenes de distinto origen social. Lindgren, Oskarsson y Dawes (2017, “Can Political Inequalities Be Educated Away?”, American Journal of Political Science) muestran que una reforma educativa sueca redujo la brecha de participación según origen social, y esa es la hipótesis sustantiva que se evalúa aquí: la asignatura podría reducir la brecha social en participación aunque no cambie el nivel.

El enfoque se adapta de Strello, Strietholt, Steinmann y Siepmann (2021, “Early tracking and different types of inequalities in achievement”, Educational Assessment, Evaluation and Accountability). Para evaluar la selección temprana de estudiantes, estos autores calculan en cada país cuatro medidas del rendimiento: el nivel, la dispersión, la brecha social según los libros en el hogar y la insuficiencia, es decir, la proporción bajo un umbral mínimo. Con ellas estiman una diferencia en diferencias a la Hanushek y Wößmann (2006), que compara el cambio entre primaria y secundaria en países con y sin selección temprana, por separado para cada medida y en muchos pares de estudios internacionales. Luego sintetizan las estimaciones con una media ponderada por el inverso de la varianza. Encuentran efectos claros sobre la brecha social, menores sobre la dispersión, débiles sobre la insuficiencia y nulos sobre el nivel, con estimaciones muy variables entre pares por el bajo número de países.

La traducción a este proyecto tiene cinco diferencias:

  • Unidades: las unidades son grupos de edad dentro de cada ola de la Encuesta CEP (jóvenes de 18 a 21 años y personas de 23 años o más), no países.
  • Períodos: el período previo es la CEP 85, en la que casi ningún joven había cursado la asignatura, y los posteriores son las olas 92 en adelante; cada combinación de la CEP 85 con una ola posterior es un “par de estudios”. En el voto, que se refiere a una sola elección, los pares son años de nacimiento.
  • Origen social: la brecha se define con el nivel educacional del jefe de hogar (educ_jefe) en lugar de los libros en el hogar.
  • Incertidumbre: hay pocas unidades y celdas pequeñas, por lo que los errores estándar se obtienen por bootstrap dentro de cada celda.
  • Datos faltantes: se trabaja con casos completos, sin imputación múltiple.

Strello et al. estandarizan los efectos con la desviación estándar de cada medida entre países. Con tan pocas unidades eso no es posible, por lo que aquí los efectos sobre el nivel, la dispersión y la brecha se dividen por la desviación estándar individual del resultado en el grupo de comparación en la CEP 85, y la insuficiencia se reporta en puntos porcentuales.

Resumen

La tabla resume el estimador principal de cada medida y resultado. En interés y confianza es la síntesis por el inverso de la varianza de los pares de olas, con el grupo de comparación de 23 años o más y sin ponderador. En el voto es el estimador agrupado, que compara a los nacidos en 2003 con todos los nacidos antes. Entre paréntesis se presenta el error estándar bootstrap, y entre corchetes el efecto estandarizado (en desviaciones estándar del resultado) o, en la insuficiencia, el efecto en puntos porcentuales. Una brecha negativa indica que la brecha a favor del origen alto se redujo. De las 10 estimaciones de la tabla, 3 son significativas al 5%: el nivel y la brecha social de la confianza política y el nivel del voto. Ninguna medida del interés político cambia de forma significativa, y la reducción de la brecha en la confianza depende de cómo se mide el origen social, como se discute en la sección B.

## Estadísticos ponderados --------------------------------------------------------
wmean <- function(x, w) if (length(x) == 0) NA_real_ else sum(w * x) / sum(w)
wsd <- function(x, w) {
  if (length(x) < 2) return(NA_real_)
  m <- wmean(x, w)
  sqrt(sum(w * (x - m)^2) / sum(w))
}
wmedian <- function(x, w) {
  if (length(x) == 0) return(NA_real_)
  o <- order(x)
  x[o][which(cumsum(w[o]) / sum(w) >= 0.5)[1]]
}
# Desviación absoluta media respecto de la mediana
mad_med <- function(x, w) wmean(abs(x - wmedian(x, w)), w)
# Índice ordinal de Leik: D = 2 * suma(d_i) / (K - 1), con d_i = F_i si F_i <= 0,5
# y 1 - F_i en otro caso, donde F_i es la proporción acumulada hasta la categoría i
leik <- function(x, w, K) {
  if (length(x) == 0) return(NA_real_)
  # Suma de pesos por categoría (más rápido que factor y tapply en el bootstrap)
  F <- cumsum(vapply(seq_len(K), function(k) sum(w[x == k]), numeric(1))) / sum(w)
  d <- ifelse(F <= 0.5, F, 1 - F)
  2 * sum(d[-K]) / (K - 1)
}

## Medidas de una celda -----------------------------------------------------------
nombres_medidas <- c("nivel", "de", "mad", "leik", "insuf1", "insuf2",
                     "brecha", "brecha_rel", "brecha_gse", "brecha_gse_rel")

medidas <- function(y, ins1, ins2, alto, galto, w, K) {
  de <- wsd(y, w)
  # Diferencia de medias entre origen alto (1) y bajo (0); los NA quedan fuera
  brecha <- function(g) {
    a <- which(g == 1)
    b <- which(g == 0)
    if (!length(a) || !length(b)) return(NA_real_)
    wmean(y[a], w[a]) - wmean(y[b], w[b])
  }
  br <- brecha(alto)
  bg <- brecha(galto)
  c(nivel = wmean(y, w), de = de, mad = mad_med(y, w),
    leik = if (is.na(K)) NA_real_ else leik(y, w, K),
    insuf1 = wmean(ins1, w), insuf2 = wmean(ins2, w),
    brecha = br, brecha_rel = br / de, brecha_gse = bg, brecha_gse_rel = bg / de)
}

## Celdas, medidas y diferencias en diferencias -----------------------------------
# Índices de cada combinación de grupo y período
armar_celdas <- function(grupos, periodos) {
  out <- list()
  for (g in names(grupos)) for (p in names(periodos)) {
    out[[paste(g, p, sep = "_")]] <- which(grupos[[g]] & periodos[[p]])
  }
  out
}

# Arreglo celda x medida x ponderación ("sin" y "con" pond)
calcular <- function(d, celdas, K) {
  A <- array(NA_real_, c(length(celdas), length(nombres_medidas), 2),
             dimnames = list(names(celdas), nombres_medidas, c("sin", "con")))
  for (p in c("sin", "con")) {
    w <- if (p == "sin") rep(1, length(d$y)) else d$pond
    for (cc in names(celdas)) {
      i <- celdas[[cc]]
      A[cc, , p] <- medidas(d$y[i], d$ins1[i], d$ins2[i], d$alto[i], d$galto[i], w[i], K)
    }
  }
  A
}

# Delta = [M(a) - M(b)] - [M(c) - M(e)]: a y b son el grupo tratado después y
# antes, c y e el grupo de comparación después y antes
calcular_deltas <- function(A, pares) {
  D <- (A[pares$a, , , drop = FALSE] - A[pares$b, , , drop = FALSE]) -
    (A[pares$c, , , drop = FALSE] - A[pares$e, , , drop = FALSE])
  dimnames(D)[[1]] <- pares$id
  D
}

# Bootstrap estratificado: remuestrea personas dentro de cada estrato y recalcula
# todas las medidas y todos los pares en cada réplica
bootstrap <- function(d, celdas, pares, estrato, K) {
  set.seed(semilla)
  estratos <- split(seq_len(nrow(d)), estrato, drop = TRUE)
  cols <- as.list(d[c("y", "ins1", "ins2", "alto", "galto", "pond")])
  reps <- array(NA_real_, c(B, nrow(pares), length(nombres_medidas), 2),
                dimnames = list(NULL, pares$id, nombres_medidas, c("sin", "con")))
  for (b in seq_len(B)) {
    idx <- seq_len(nrow(d))
    for (s in estratos) idx[s] <- s[sample.int(length(s), length(s), replace = TRUE)]
    reps[b, , , ] <- calcular_deltas(calcular(lapply(cols, function(v) v[idx]), celdas, K), pares)
    # Pausa breve cada 100 réplicas para no mantener el procesador al máximo
    if (b %% 100 == 0) Sys.sleep(pausa)
  }
  reps
}

# Síntesis de los pares: media ponderada por el inverso de la varianza, con su
# error estándar analítico y el bootstrap con los pesos fijos, y pesos iguales
sintetizar <- function(delta, reps) {
  se <- apply(reps, 2, stats::sd, na.rm = TRUE)
  ok <- is.finite(delta) & is.finite(se) & se > 0
  if (!any(ok)) return(c(est = NA, se_an = NA, se_boot = NA, est_eq = NA, se_eq = NA, n = 0))
  w <- (1 / se[ok]^2) / sum(1 / se[ok]^2)
  r <- reps[, ok, drop = FALSE]
  c(est = sum(w * delta[ok]), se_an = sqrt(1 / sum(1 / se[ok]^2)),
    se_boot = stats::sd(r %*% w, na.rm = TRUE),
    est_eq = mean(delta[ok]), se_eq = stats::sd(rowMeans(r), na.rm = TRUE), n = sum(ok))
}

# Réplicas de un conjunto de pares como matriz B x pares
matriz <- function(R, ids, m, p) matrix(R[, ids, m, p], nrow = dim(R)[1])

estrellas <- function(p) dplyr::case_when(p < 0.001 ~ "***", p < 0.01 ~ "**", p < 0.05 ~ "*", TRUE ~ "")

# Tabla de síntesis de un resultado: cada comparación, ponderación y medida
resumir <- function(D, R, pares, sd_ref, resultado) {
  tipos <- c(agrupado = "Agrupado", agrupado_9802 = "Agrupado, nacidos 1998-2002")
  filas <- list()
  for (comp in unique(pares$comp)) for (p in c("sin", "con")) for (m in nombres_medidas) {
    ks <- pares$id[pares$comp == comp & pares$tipo == "par"]
    s <- sintetizar(D[ks, m, p], matriz(R, ks, m, p))
    f <- data.frame(tipo = c("Inverso de la varianza", "Pesos iguales"),
                    est = c(s[["est"]], s[["est_eq"]]), se = c(s[["se_boot"]], s[["se_eq"]]),
                    se_an = c(s[["se_an"]], NA), n_pares = s[["n"]])
    if (m %in% c("brecha", "brecha_rel")) {
      ks2 <- ks[pares$min_sub[match(ks, pares$id)] >= 15]
      s2 <- sintetizar(D[ks2, m, p], matriz(R, ks2, m, p))
      f <- rbind(f, data.frame(tipo = "Inverso de la varianza, sin pares con celdas de menos de 15 casos",
                               est = s2[["est"]], se = s2[["se_boot"]], se_an = s2[["se_an"]], n_pares = s2[["n"]]))
    }
    for (t in intersect(names(tipos), pares$tipo[pares$comp == comp])) {
      ag <- pares$id[pares$comp == comp & pares$tipo == t]
      f <- rbind(f, data.frame(tipo = tipos[[t]], est = D[ag, m, p],
                               se = stats::sd(R[, ag, m, p], na.rm = TRUE), se_an = NA, n_pares = NA))
    }
    filas[[length(filas) + 1]] <- data.frame(resultado, comp, pond = p, medida = m, f)
  }
  out <- dplyr::bind_rows(filas)
  out$sd_ref <- sd_ref[cbind(out$comp, out$pond)]
  out %>%
    dplyr::mutate(p = 2 * stats::pnorm(-abs(est / se)),
                  estrellas = estrellas(p),
                  efecto = dplyr::case_when(medida %in% estandarizables ~ est / sd_ref,
                                            medida %in% c("insuf1", "insuf2") ~ 100 * est,
                                            TRUE ~ NA_real_),
                  se_efecto = dplyr::case_when(medida %in% estandarizables ~ se / sd_ref,
                                               medida %in% c("insuf1", "insuf2") ~ 100 * se,
                                               TRUE ~ NA_real_))
}

# Menor subcelda de origen social entre las cuatro celdas de cada par
min_sub <- function(n, pares) {
  sub <- pmin(n[, "n_alto"], n[, "n_bajo"])

}

Interés y confianza usan la muestra de casos completos del diseño 2x2 de analysis_did_principal.qmd (edades de 18 a 21 y de 23 años o más, CEP 85 y olas 92 en adelante, con nivel educacional, grupo socioeconómico, edad y ponderador), restringida además a los casos con educación del jefe de hogar, de modo que las cuatro medidas se calculan sobre los mismos casos. A) Interés político

Las celdas combinan la ola (CEP 85 y olas 92, 93, 95 y 96) con el grupo de edad: jóvenes de 18 a 21 años, personas de 23 años o más (comparación principal) y de 23 a 29 años (robustez). Cada par de estudios compara la CEP 85 con una ola posterior, y el estimador agrupado junta todas las olas posteriores. El bootstrap remuestrea personas dentro de cada celda de ola, grupo de edad (18 a 21, 23 a 29 y 30 o más) y origen social, de modo que ninguna réplica queda con celdas vacías. La dispersión se mide con la desviación estándar y, como robustez, con la desviación absoluta media respecto de la mediana y el índice ordinal de Leik. La insuficiencia es la proporción “nada interesada” y, como robustez, la proporción “nada” o “no muy interesada”.

La síntesis por el inverso de la varianza informa dos errores estándar. El analítico, √(1/Σw), es el que usan Strello et al. y supone que los pares son independientes. Aquí todos los pares comparten la CEP 85, por lo que sus estimaciones están correlacionadas y ese error subestima la incertidumbre; el error bootstrap del promedio ponderado con los pesos fijos incorpora esa correlación y es el que se usa para las pruebas.

Chequeos con regresión

Los chequeos estiman las mismas diferencias en diferencias con regresiones individuales, efectos fijos de ola y de edad, y errores HC1, con la comparación de 23 años o más y sin ponderador. La brecha se estima con una triple diferencia (joven × post × origen alto), cuyo coeficiente es la diferencia en diferencias de la brecha. La dispersión se estima sobre la desviación cuadrática respecto de la media de la celda de ola y grupo, cuyo promedio en la celda es la varianza.

       "Brecha" = lm(y ~ factor(edad_nac) + factor(ola) * alto + joven * post * alto, data = d),

B) Confianza política

El diseño es el mismo que en el interés político, con la CEP 85 y las olas 92 a 96. La confianza política es el promedio de tres ítems de 1 a 4, por lo que no tiene categorías ordinales y no se calcula el índice de Leik. La insuficiencia es la proporción sin confianza en ninguna de las tres instituciones (suma de los tres ítems igual a 3) y, como robustez, la proporción con una suma de hasta 4, es decir, con “poca” confianza en a lo más una institución. El umbral de “hasta 2” en el promedio dejaba al 89% de la CEP 85 bajo el umbral, por lo que no distinguía insuficiencia.

La CEP 85 se levantó durante el gobierno de Sebastián Piñera, las olas 92 a 95 durante el de Gabriel Boric y la 96 durante el gobierno que asumió en marzo de 2026. Si la confianza de los jóvenes en el Gobierno cambió de forma distinta a la de los adultos con el cambio de gobierno, ese cambio podría explicar los resultados sin relación con la asignatura. Para evaluarlo, el nivel y la brecha se estiman por separado para la confianza en los partidos políticos, en el Congreso y en el Gobierno, y para un índice que excluye el ítem de Gobierno (promedio de partidos y Congreso). Se usan la misma muestra, las mismas celdas y las mismas réplicas bootstrap que en el índice completo.

Una brecha que disminuye puede deberse a que sube la confianza de los jóvenes de origen bajo, a que baja la de los jóvenes de origen alto, o a ambas cosas. Interpretación

En la confianza política el nivel aumenta: el estimador sintetizado es 0,200** (EE 0,064), equivalente a 0,37 desviaciones estándar, en línea con el modelo 1 de analysis_did_principal.qmd. El aumento es positivo en las tres instituciones, aunque solo es significativo en la confianza en el Congreso: partidos (0,144 (EE 0,080)), Congreso (0,272*** (EE 0,082)) y Gobierno (0,170 (EE 0,093)), y el índice sin el ítem de Gobierno da un resultado similar al del índice completo (0,211** (EE 0,068)). Por eso no parece explicarse solo por un cambio en la confianza de los jóvenes en el Gobierno de turno. Por pares, el Delta del nivel va de 0,193 y 0,259 en los pares 85-92 a 85-95, y es menor en el par 85-96 (0,117 [-0,051; 0,286], con intervalo al 95% entre corchetes), la única ola levantada bajo el gobierno que asumió en 2026; con un solo par no es posible distinguir si esa diferencia refleja el cambio de gobierno o variación muestral.

La brecha social según la educación del jefe de hogar se reduce: -0,298* (EE 0,123), es decir, -0,56 desviaciones estándar. Es la forma de desigualdad que, según la hipótesis de Lindgren, Oskarsson y Dawes, podría cambiar aunque el nivel no cambie. Las tablas complementarias muestran de dónde viene esta reducción:

  • Dirección: la brecha baja porque aumenta la confianza de los jóvenes de origen bajo (diferencia en diferencias del nivel de 0,311*** (EE 0,088)), mientras que la de los jóvenes de origen alto no cambia (0,017 (EE 0,084)). Entre los jóvenes, la confianza media pasa de 1,51 a 1,90 en el origen bajo y de 1,76 a 1,92 en el origen alto, de modo que la brecha se cierra (de 0,25 a 0,02) sin cambiar de signo.
  • Brecha inicial: en la CEP 85 la brecha de los jóvenes (0,25) era mucho mayor que la del grupo de comparación (0,05), y se calcula con solo 28 jóvenes de origen alto. Parte de la reducción posterior puede reflejar regresión a la media de una brecha inicial alta por azar muestral, más que un efecto de la asignatura.
  • Por institución: el estimador de la brecha es negativo con los tres ítems, aunque solo es significativo en la confianza en los partidos (partidos -0,470** (EE 0,174), Congreso -0,184 (EE 0,160) y Gobierno -0,230 (EE 0,186)) y con el índice sin Gobierno (-0,313* (EE 0,139)), por lo que tampoco depende del ítem de Gobierno.
  • Por par: la reducción aparece en casi todos los pares, con la excepción del par 85-95 (-0,064 [-0,422; 0,293]); el par 85-96 (-0,272 [-0,600; 0,057]) no se aparta de los demás.

La reducción se mantiene con pesos iguales (-0,304* (EE 0,124)), con las olas posteriores agrupadas (-0,287* (EE 0,123)), sin los pares con celdas de menos de 15 casos (-0,260* (EE 0,126)), con el ponderador (-0,296* (EE 0,144)) y en la triple diferencia con regresión individual (-0,292 (EE 0,124, p = 0,019)). Aun así, hay cuatro razones para no tomarla como evidencia de un efecto de la asignatura:

  • Comparaciones múltiples: 22 de las 116 estimaciones sintetizadas de esta sección son significativas al 5%, y varias de ellas son versiones de las mismas dos medidas, por lo que no son evidencia independiente.
  • Comparación de 23 a 29 años: el estimador es de magnitud similar (-0,268 (EE 0,156)), pero no es significativo. Esta comparación importa porque educ_jefe corresponde a la educación de los padres entre los jóvenes que viven con ellos y suele ser la propia entre las personas mayores, que más a menudo son jefes de hogar.
  • Grupo socioeconómico: cuando el origen social se mide con él, la brecha no se reduce (0,106 (EE 0,140)), de modo que el resultado depende de la operacionalización del origen.
  • Brecha inicial y regresión a la media: como se indicó, la brecha de los jóvenes en la CEP 85 era inusualmente alta y descansa en pocos casos.

El error estándar analítico de la síntesis de la brecha (0,079) es menor que el bootstrap, porque no considera que todos los pares comparten la CEP 85. Entre la CEP 85 y las olas posteriores los jóvenes difieren también en su exposición al Plan de Formación Ciudadana, y el período posterior coincide con cambios en la confianza institucional que pueden haber afectado de forma distinta a jóvenes y adultos.

C) Voto

El voto usa el diseño por cohorte de nacimiento de analysis_did_principal.qmd. Las celdas combinan el momento del año de nacimiento (abril a diciembre, tardio = 1, o enero a marzo) con el año de nacimiento. El estimador principal es el agrupado: Delta = [M(tardío, 2003) − M(temprano, 2003)] − [M(tardío, antes de 2003) − M(temprano, antes de 2003)]. Como sensibilidad, cada año de nacimiento entre 1998 y 2002 forma un par con 2003 y los pares se sintetizan; como robustez, el estimador agrupado se restringe a los nacidos entre 1998 y 2002. En una variable dicotómica la desviación estándar es función de la proporción y la insuficiencia equivale a no votar, por lo que solo se estiman el nivel y la brecha. El bootstrap remuestrea personas dentro de cada combinación de año de nacimiento, momento del año y origen social.

D) Placebo con olas previas (interés político)

Si las tendencias de jóvenes y personas mayores fueran paralelas, las diferencias en diferencias entre olas en que ningún joven había cursado la asignatura deberían ser cercanas a cero. El placebo usa la base extendida de interés político (data_int_ext) y compara cada ola previa (77, 82, 83 y 84) con la CEP 85: Delta = [M(joven, 85) − M(joven, k)] − [M(comparación, 85) − M(comparación, k)], con la comparación de 23 años o más. La ola 81 queda fuera porque su escala no incluye “no muy interesado”. Estas olas no tienen la educación del jefe de hogar, por lo que la brecha se calcula con el grupo socioeconómico, disponible en las olas 82, 83 y 85.

La exposición al Plan de Formación Ciudadana (Ley 20.911, desde 2016) difiere entre las olas. Los jóvenes de la CEP 85 tenían varios años de Plan durante su escolaridad, mientras que los de las olas 77 a 84 tenían poca o ninguna exposición. Por eso un placebo distinto de cero puede reflejar el efecto del Plan y no necesariamente una violación del supuesto de tendencias paralelas. La tabla de dosis muestra los años promedio de Plan en cada celda.

E) Propensity score matching

Como comparación descriptiva, se reutiliza el emparejamiento de la muestra de hasta 30 años con covariables adicionales de analysis_psm.qmd (sexo, nivel educacional, grupo socioeconómico, región, zona, pueblo originario y educación del jefe de hogar, vecino más cercano con caliper de 0,01), agregando emparejamiento exacto por ola y por origen social, para comparar las brechas dentro de cada estrato. En la muestra emparejada se estiman el nivel (ATT), la dispersión (DE de tratados menos DE de controles), la brecha (brecha en tratados menos brecha en controles) y la insuficiencia (diferencia de proporciones). Los errores estándar se obtienen por bootstrap de pares emparejados, remuestreando las subclases (Abadie y Spiess, 2022). Si el emparejamiento deja menos de 30 tratados de algún origen social, sumando las olas, solo se estiman el nivel, la dispersión y la insuficiencia. Se reporta además el ATT de nivel con la especificación de la sección de hasta 30 años de analysis_psm.qmd, sin emparejamiento exacto, para compararlo con el resumen de esa pestaña.

La edad no puede balancearse, porque el tratamiento es función de la edad: los tratados tienen entre 17 y 22 años y sus controles, hasta 30. Estas estimaciones mezclan el efecto de la asignatura con el de la edad y sirven solo como comparación descriptiva.

# Medidas en la muestra emparejada: tratados menos controles
psm_medidas <- function(md, voto) {
  t <- md$educacion_ciudadana == 1
  w <- md$weights
  m <- function(s) wmean(md$y[s], w[s])
  br <- function(s) m(s & md$origen_alto == 1) - m(s & md$origen_alto == 0)
  c(nivel = m(t) - m(!t),
    de = if (voto) NA_real_ else wsd(md$y[t], w[t]) - wsd(md$y[!t], w[!t]),
    brecha = br(t) - br(!t),
    insuf1 = if (voto) NA_real_ else wmean(md$ins1[t], w[t]) - wmean(md$ins1[!t], w[!t]))
}
# Bootstrap de pares emparejados: remuestreo de subclases
psm_boot <- function(md, voto) {
  set.seed(semilla)
  sub <- split(seq_len(nrow(md)), md$subclass, drop = TRUE)
  t(replicate(B, psm_medidas(md[unlist(sub[sample.int(length(sub), length(sub), replace = TRUE)]), ], voto)))
}

# Qué se hace y por qué

## Qué se hace

Este documento estima el efecto de la asignatura de Educación Ciudadana sobre cuatro medidas de la distribución del interés político, la confianza política y el voto en la 2ª vuelta presidencial de 2021: el nivel (la media o la proporción), la dispersión (la desviación estándar), la brecha social (la diferencia entre personas de origen social alto y bajo) y la insuficiencia (la proporción bajo un umbral mínimo). Cada medida se calcula en celdas de ola y grupo de edad, y el efecto se estima con una diferencia en diferencias sobre esas medidas, siguiendo los diseños de la pestaña [Diferencia en diferencias](analysis_did_principal.qmd). Las estimaciones se complementan con chequeos de regresión individual, pruebas de robustez, un placebo con olas previas a la asignatura y una comparación descriptiva con emparejamiento por puntaje de propensión.

## Por qué se hace

Los análisis anteriores evalúan si la asignatura cambió el promedio de cada resultado. Una política educativa puede, sin embargo, afectar la distribución sin mover el promedio, por ejemplo reduciendo la distancia entre jóvenes de distinto origen social. Lindgren, Oskarsson y Dawes (2017, "Can Political Inequalities Be Educated Away?", *American Journal of Political Science*) muestran que una reforma educativa sueca redujo la brecha de participación según origen social, y esa es la hipótesis sustantiva que se evalúa aquí: la asignatura podría reducir la brecha social en participación aunque no cambie el nivel.

El enfoque se adapta de Strello, Strietholt, Steinmann y Siepmann (2021, "Early tracking and different types of inequalities in achievement", *Educational Assessment, Evaluation and Accountability*). Para evaluar la selección temprana de estudiantes, estos autores calculan en cada país cuatro medidas del rendimiento: el nivel, la dispersión, la brecha social según los libros en el hogar y la insuficiencia, es decir, la proporción bajo un umbral mínimo. Con ellas estiman una diferencia en diferencias a la Hanushek y Wößmann (2006), que compara el cambio entre primaria y secundaria en países con y sin selección temprana, por separado para cada medida y en muchos pares de estudios internacionales. Luego sintetizan las estimaciones con una media ponderada por el inverso de la varianza. Encuentran efectos claros sobre la brecha social, menores sobre la dispersión, débiles sobre la insuficiencia y nulos sobre el nivel, con estimaciones muy variables entre pares por el bajo número de países.

La traducción a este proyecto tiene cinco diferencias:

- **Unidades:** las unidades son grupos de edad dentro de cada ola de la Encuesta CEP (jóvenes de 18 a 21 años y personas de 23 años o más), no países.
- **Períodos:** el período previo es la CEP 85, en la que casi ningún joven había cursado la asignatura, y los posteriores son las olas 92 en adelante; cada combinación de la CEP 85 con una ola posterior es un "par de estudios". En el voto, que se refiere a una sola elección, los pares son años de nacimiento.
- **Origen social:** la brecha se define con el nivel educacional del jefe de hogar (`educ_jefe`) en lugar de los libros en el hogar.
- **Incertidumbre:** hay pocas unidades y celdas pequeñas, por lo que los errores estándar se obtienen por bootstrap dentro de cada celda.
- **Datos faltantes:** se trabaja con casos completos, sin imputación múltiple.

Strello et al. estandarizan los efectos con la desviación estándar de cada medida entre países. Con tan pocas unidades eso no es posible, por lo que aquí los efectos sobre el nivel, la dispersión y la brecha se dividen por la desviación estándar individual del resultado en el grupo de comparación en la CEP 85, y la insuficiencia se reporta en puntos porcentuales.

leik <- function(x, w, K) {
  if (length(x) == 0) return(NA_real_)
  # Suma de pesos por categoría (más rápido que factor y tapply en el bootstrap)
  F <- cumsum(vapply(seq_len(K), function(k) sum(w[x == k]), numeric(1))) / sum(w)
  d <- ifelse(F <= 0.5, F, 1 - F)
  2 * sum(d[-K]) / (K - 1)
}

## Medidas de una celda -----------------------------------------------------------
nombres_medidas <- c("nivel", "de", "mad", "leik", "insuf1", "insuf2",
                     "brecha", "brecha_rel", "brecha_gse", "brecha_gse_rel")

medidas <- function(y, ins1, ins2, alto, galto, w, K) {
  de <- wsd(y, w)
  # Diferencia de medias entre origen alto (1) y bajo (0); los NA quedan fuera
  brecha <- function(g) {
    a <- which(g == 1)
    b <- which(g == 0)
    if (!length(a) || !length(b)) return(NA_real_)
    wmean(y[a], w[a]) - wmean(y[b], w[b])
  }
  br <- brecha(alto)
  bg <- brecha(galto)
  c(nivel = wmean(y, w), de = de, mad = mad_med(y, w),
    leik = if (is.na(K)) NA_real_ else leik(y, w, K),
    insuf1 = wmean(ins1, w), insuf2 = wmean(ins2, w),
    brecha = br, brecha_rel = br / de, brecha_gse = bg, brecha_gse_rel = bg / de)
}

## Celdas, medidas y diferencias en diferencias -----------------------------------
# Índices de cada combinación de grupo y período
armar_celdas <- function(grupos, periodos) {
  out <- list()
  for (g in names(grupos)) for (p in names(periodos)) {
    out[[paste(g, p, sep = "_")]] <- which(grupos[[g]] & periodos[[p]])
  }
  out
}

# Arreglo celda x medida x ponderación ("sin" y "con" pond)
calcular <- function(d, celdas, K) {
  A <- array(NA_real_, c(length(celdas), length(nombres_medidas), 2),
             dimnames = list(names(celdas), nombres_medidas, c("sin", "con")))
  for (p in c("sin", "con")) {
    w <- if (p == "sin") rep(1, length(d$y)) else d$pond
    for (cc in names(celdas)) {
      i <- celdas[[cc]]
      A[cc, , p] <- medidas(d$y[i], d$ins1[i], d$ins2[i], d$alto[i], d$galto[i], w[i], K)
    }
  }
  A
}

# Delta = [M(a) - M(b)] - [M(c) - M(e)]: a y b son el grupo tratado después y
# antes, c y e el grupo de comparación después y antes
calcular_deltas <- function(A, pares) {
  D <- (A[pares$a, , , drop = FALSE] - A[pares$b, , , drop = FALSE]) -
    (A[pares$c, , , drop = FALSE] - A[pares$e, , , drop = FALSE])
  dimnames(D)[[1]] <- pares$id
  D
}

# Bootstrap estratificado: remuestrea personas dentro de cada estrato y recalcula
# todas las medidas y todos los pares en cada réplica
bootstrap <- function(d, celdas, pares, estrato, K) {
  set.seed(semilla)
  estratos <- split(seq_len(nrow(d)), estrato, drop = TRUE)
  cols <- as.list(d[c("y", "ins1", "ins2", "alto", "galto", "pond")])
  reps <- array(NA_real_, c(B, nrow(pares), length(nombres_medidas), 2),
                dimnames = list(NULL, pares$id, nombres_medidas, c("sin", "con")))
  for (b in seq_len(B)) {
    idx <- seq_len(nrow(d))
    for (s in estratos) idx[s] <- s[sample.int(length(s), length(s), replace = TRUE)]
    reps[b, , , ] <- calcular_deltas(calcular(lapply(cols, function(v) v[idx]), celdas, K), pares)
    # Pausa breve cada 100 réplicas para no mantener el procesador al máximo
    if (b %% 100 == 0) Sys.sleep(pausa)
  }
  reps
}

# Síntesis de los pares: media ponderada por el inverso de la varianza, con su
# error estándar analítico y el bootstrap con los pesos fijos, y pesos iguales
sintetizar <- function(delta, reps) {
  se <- apply(reps, 2, stats::sd, na.rm = TRUE)
  ok <- is.finite(delta) & is.finite(se) & se > 0
  if (!any(ok)) return(c(est = NA, se_an = NA, se_boot = NA, est_eq = NA, se_eq = NA, n = 0))
  w <- (1 / se[ok]^2) / sum(1 / se[ok]^2)
  r <- reps[, ok, drop = FALSE]
  c(est = sum(w * delta[ok]), se_an = sqrt(1 / sum(1 / se[ok]^2)),
    se_boot = stats::sd(r %*% w, na.rm = TRUE),
    est_eq = mean(delta[ok]), se_eq = stats::sd(rowMeans(r), na.rm = TRUE), n = sum(ok))
}

# Réplicas de un conjunto de pares como matriz B x pares
matriz <- function(R, ids, m, p) matrix(R[, ids, m, p], nrow = dim(R)[1])

estrellas <- function(p) dplyr::case_when(p < 0.001 ~ "***", p < 0.01 ~ "**", p < 0.05 ~ "*", TRUE ~ "")

etiquetas_medidas <- c(nivel = "Nivel", de = "Dispersión (DE)",

                       insuf2 = "Insuficiencia (umbral alternativo)",
                       brecha = "Brecha social (educación del jefe de hogar)",
                       brecha_rel = "Brecha social relativa (educación del jefe de hogar)",
                       brecha_gse = "Brecha social (GSE)", brecha_gse_rel = "Brecha social relativa (GSE)")
estandarizables <- c("nivel", "de", "mad", "brecha", "brecha_gse")

# Tabla de síntesis de un resultado: cada comparación, ponderación y medida
resumir <- function(D, R, pares, sd_ref, resultado) {
  tipos <- c(agrupado = "Agrupado", agrupado_9802 = "Agrupado, nacidos 1998-2002")
  filas <- list()
  for (comp in unique(pares$comp)) for (p in c("sin", "con")) for (m in nombres_medidas) {
    ks <- pares$id[pares$comp == comp & pares$tipo == "par"]
    s <- sintetizar(D[ks, m, p], matriz(R, ks, m, p))
    f <- data.frame(tipo = c("Inverso de la varianza", "Pesos iguales"),
                    est = c(s[["est"]], s[["est_eq"]]), se = c(s[["se_boot"]], s[["se_eq"]]),
                    se_an = c(s[["se_an"]], NA), n_pares = s[["n"]])
    if (m %in% c("brecha", "brecha_rel")) {
      ks2 <- ks[pares$min_sub[match(ks, pares$id)] >= 15]
      s2 <- sintetizar(D[ks2, m, p], matriz(R, ks2, m, p))
      f <- rbind(f, data.frame(tipo = "Inverso de la varianza, sin pares con celdas de menos de 15 casos",
                               est = s2[["est"]], se = s2[["se_boot"]], se_an = s2[["se_an"]], n_pares = s2[["n"]]))
    }
    for (t in intersect(names(tipos), pares$tipo[pares$comp == comp])) {
      ag <- pares$id[pares$comp == comp & pares$tipo == t]
      f <- rbind(f, data.frame(tipo = tipos[[t]], est = D[ag, m, p],
                               se = stats::sd(R[, ag, m, p], na.rm = TRUE), se_an = NA, n_pares = NA))
    }
    filas[[length(filas) + 1]] <- data.frame(resultado, comp, pond = p, medida = m, f)
  }
  out <- dplyr::bind_rows(filas)
  out$sd_ref <- sd_ref[cbind(out$comp, out$pond)]
  out %>%
    dplyr::mutate(p = 2 * stats::pnorm(-abs(est / se)),
                  estrellas = estrellas(p),
                  efecto = dplyr::case_when(medida %in% estandarizables ~ est / sd_ref,
                                            medida %in% c("insuf1", "insuf2") ~ 100 * est,
                                            TRUE ~ NA_real_),
                  se_efecto = dplyr::case_when(medida %in% estandarizables ~ se / sd_ref,
                                               medida %in% c("insuf1", "insuf2") ~ 100 * se,
                                               TRUE ~ NA_real_))
}

# B) Confianza política

El diseño es el mismo que en el interés político, con la CEP 85 y las olas 92 a 96. ## Interpretación

En la confianza política el nivel aumenta: el estimador sintetizado es `r tx(sint_conf, "c23", "nivel")`, equivalente a `r efe(sint_conf, "c23", "nivel")` desviaciones estándar, en línea con el modelo 1 de `analysis_did_principal.qmd`. El aumento es positivo en las tres instituciones, aunque solo es significativo en la confianza en el Congreso: partidos (`r tx_item("conf_partidos", "nivel")`), Congreso (`r tx_item("conf_congreso", "nivel")`) y Gobierno (`r tx_item("conf_gobierno", "nivel")`), y el índice sin el ítem de Gobierno da un resultado similar al del índice completo (`r tx_item("conf_sin_gob", "nivel")`). Por eso no parece explicarse solo por un cambio en la confianza de los jóvenes en el Gobierno de turno. Por pares, el Delta del nivel va de `r rango_par("nivel")` en los pares 85-92 a 85-95, y es menor en el par 85-96 (`r tx_par("nivel", "85-96")`, con intervalo al 95% entre corchetes), la única ola levantada bajo el gobierno que asumió en 2026; con un solo par no es posible distinguir si esa diferencia refleja el cambio de gobierno o variación muestral.

La brecha social según la educación del jefe de hogar se reduce: `r tx(sint_conf, "c23", "brecha")`, es decir, `r efe(sint_conf, "c23", "brecha")` desviaciones estándar. Es la forma de desigualdad que, según la hipótesis de Lindgren, Oskarsson y Dawes, podría cambiar aunque el nivel no cambie. Las tablas complementarias muestran de dónde viene esta reducción:

- **Dirección:** la brecha baja porque aumenta la confianza de los jóvenes de origen bajo (diferencia en diferencias del nivel de `r tx_origen("Origen bajo")`), mientras que la de los jóvenes de origen alto no cambia (`r tx_origen("Origen alto")`). Entre los jóvenes, la confianza media pasa de `r media_or("Jóvenes (18 a 21)", "CEP 85", "media_bajo")` a `r media_or("Jóvenes (18 a 21)", "Olas 92 a 96", "media_bajo")` en el origen bajo y de `r media_or("Jóvenes (18 a 21)", "CEP 85", "media_alto")` a `r media_or("Jóvenes (18 a 21)", "Olas 92 a 96", "media_alto")` en el origen alto, de modo que la brecha se cierra (de `r media_or("Jóvenes (18 a 21)", "CEP 85", "brecha")` a `r media_or("Jóvenes (18 a 21)", "Olas 92 a 96", "brecha")`) sin cambiar de signo.
- **Brecha inicial:** en la CEP 85 la brecha de los jóvenes (`r media_or("Jóvenes (18 a 21)", "CEP 85", "brecha")`) era mucho mayor que la del grupo de comparación (`r media_or("Comparación (23 o más)", "CEP 85", "brecha")`), y se calcula con solo `r medias_origen$n_alto[medias_origen$grupo2 == "Jóvenes (18 a 21)" & medias_origen$periodo == "CEP 85"]` jóvenes de origen alto. Parte de la reducción posterior puede reflejar regresión a la media de una brecha inicial alta por azar muestral, más que un efecto de la asignatura.
- **Por institución:** el estimador de la brecha es negativo con los tres ítems, aunque solo es significativo en la confianza en los partidos (partidos `r tx_item("conf_partidos", "brecha")`, Congreso `r tx_item("conf_congreso", "brecha")` y Gobierno `r tx_item("conf_gobierno", "brecha")`) y con el índice sin Gobierno (`r tx_item("conf_sin_gob", "brecha")`), por lo que tampoco depende del ítem de Gobierno.
- **Por par:** la reducción aparece en casi todos los pares, con la excepción del par 85-95 (`r tx_par("brecha", "85-95")`); el par 85-96 (`r tx_par("brecha", "85-96")`) no se aparta de los demás.

La reducción se mantiene con pesos iguales (`r tx(sint_conf, "c23", "brecha", "Pesos iguales")`), con las olas posteriores agrupadas (`r tx(sint_conf, "c23", "brecha", "Agrupado")`), sin los pares con celdas de menos de 15 casos (`r tx(sint_conf, "c23", "brecha", "Inverso de la varianza, sin pares con celdas de menos de 15 casos")`), con el ponderador (`r tx(sint_conf, "c23", "brecha", p = "con")`) y en la triple diferencia con regresión individual (`r coef_reg(reg_conf, "Brecha", "alto:joven:post")`). Aun así, hay cuatro razones para no tomarla como evidencia de un efecto de la asignatura:

- **Comparaciones múltiples:** `r n_sig(sint_conf)` de las `r n_tot(sint_conf)` estimaciones sintetizadas de esta sección son significativas al 5%, y varias de ellas son versiones de las mismas dos medidas, por lo que no son evidencia independiente.
- **Comparación de 23 a 29 años:** el estimador es de magnitud similar (`r tx(sint_conf, "c2329", "brecha")`), pero no es significativo. Esta comparación importa porque `educ_jefe` corresponde a la educación de los padres entre los jóvenes que viven con ellos y suele ser la propia entre las personas mayores, que más a menudo son jefes de hogar.
- **Grupo socioeconómico:** cuando el origen social se mide con él, la brecha no se reduce (`r tx(sint_conf, "c23", "brecha_gse")`), de modo que el resultado depende de la operacionalización del origen.
- **Brecha inicial y regresión a la media:** como se indicó, la brecha de los jóvenes en la CEP 85 era inusualmente alta y descansa en pocos casos.

El error estándar analítico de la síntesis de la brecha (`r se_an(sint_conf, "c23", "brecha")`) es menor que el bootstrap, porque no considera que todos los pares comparten la CEP 85. Entre la CEP 85 y las olas posteriores los jóvenes difieren también en su exposición al Plan de Formación Ciudadana, y el período posterior coincide con cambios en la confianza institucional que pueden haber afectado de forma distinta a jóvenes y adultos.

# C) Voto

El voto usa el diseño por cohorte de nacimiento de `analysis_did_principal.qmd`. Las celdas combinan el momento del año de nacimiento (abril a diciembre, `tardio = 1`, o enero a marzo) con el año de nacimiento. El estimador principal es el agrupado: Delta = [M(tardío, 2003) − M(temprano, 2003)] − [M(tardío, antes de 2003) − M(temprano, antes de 2003)]. Como sensibilidad, cada año de nacimiento entre 1998 y 2002 forma un par con 2003 y los pares se sintetizan; como robustez, el estimador agrupado se restringe a los nacidos entre 1998 y 2002. En una variable dicotómica la desviación estándar es función de la proporción y la insuficiencia equivale a no votar, por lo que solo se estiman el nivel y la brecha. El bootstrap remuestrea personas dentro de cada combinación de año de nacimiento, momento del año y origen social.

## Interpretación

La síntesis por año de nacimiento da un estimador menor y no significativo con el error bootstrap (`r tx(sint_voto, "cohortes", "nivel")`). Su error estándar analítico (`r se_an(sint_voto, "cohortes", "nivel")`) es casi la mitad del bootstrap y llevaría a declararlo significativo, lo que ilustra por qué el error analítico subestima la incertidumbre cuando todos los pares comparten la celda de 2003. En total, `r n_sig(sint_voto)` de las `r n_tot(sint_voto)` estimaciones de esta sección son significativas al 5%. Como en los análisis anteriores, los tratados tenían 18 años en la elección, por lo que el diseño supone que la diferencia de participación entre nacidos a inicio y a fin de año es la misma entre votantes primerizos que a edades mayores.

# D) Placebo con olas previas (interés político)

Si las tendencias de jóvenes y personas mayores fueran paralelas, las diferencias en diferencias entre olas en que ningún joven había cursado la asignatura deberían ser cercanas a cero. El placebo usa la base extendida de interés político (`data_int_ext`) y compara cada ola previa (77, 82, 83 y 84) con la CEP 85: Delta = [M(joven, 85) − M(joven, k)] − [M(comparación, 85) − M(comparación, k)], con la comparación de 23 años o más. La ola 81 queda fuera porque su escala no incluye "no muy interesado". Estas olas no tienen la educación del jefe de hogar, por lo que la brecha se calcula con el grupo socioeconómico, disponible en las olas 82, 83 y 85.

La exposición al Plan de Formación Ciudadana (Ley 20.911, desde 2016) difiere entre las olas. Los jóvenes de la CEP 85 tenían varios años de Plan durante su escolaridad, mientras que los de las olas 77 a 84 tenían poca o ninguna exposición. Por eso un placebo distinto de cero puede reflejar el efecto del Plan y no necesariamente una violación del supuesto de tendencias paralelas. # E) Propensity score matching

Como comparación descriptiva, se reutiliza el emparejamiento de la muestra de hasta 30 años con covariables adicionales de [`analysis_psm.qmd`](analysis_psm.qmd) (sexo, nivel educacional, grupo socioeconómico, región, zona, pueblo originario y educación del jefe de hogar, vecino más cercano con *caliper* de 0,01), agregando emparejamiento exacto por ola y por origen social, para comparar las brechas dentro de cada estrato. En la muestra emparejada se estiman el nivel (ATT), la dispersión (DE de tratados menos DE de controles), la brecha (brecha en tratados menos brecha en controles) y la insuficiencia (diferencia de proporciones). Los errores estándar se obtienen por bootstrap de pares emparejados, remuestreando las subclases (Abadie y Spiess, 2022). Si el emparejamiento deja menos de 30 tratados de algún origen social, sumando las olas, solo se estiman el nivel, la dispersión y la insuficiencia. Se reporta además el ATT de nivel con la especificación de la sección de hasta 30 años de `analysis_psm.qmd`, sin emparejamiento exacto, para compararlo con el resumen de esa pestaña.

La edad no puede balancearse, porque el tratamiento es función de la edad: los tratados tienen entre 17 y 22 años y sus controles, hasta 30. Estas estimaciones mezclan el efecto de la asignatura con el de la edad y sirven solo como comparación descriptiva.

psm_base <- function(d, y) {
  d %>%
    dplyr::mutate(gse3 = agrupar_gse(gse)) %>%

                                  "pueblo", "educ_jefe", "edad_nac", "ola", y))) %>%
    na.omit() %>%
    droplevels() %>%
    dplyr::mutate(y = .data[[y]], origen_alto = origen_alto(educ_jefe)) %>%
    as.data.frame()
}
psm_datos <- list(
  interes = psm_base(readRDS("input/data/proc/data_int.rds"), "int_pol") %>% dplyr::mutate(ins1 = as.numeric(y == 1)),
  confianza = psm_base(readRDS("input/data/proc/data_actitudes.rds"), "conf_pol") %>% dplyr::mutate(ins1 = as.numeric(round(y * 3) <= 3)),
  voto = psm_base(dplyr::filter(readRDS("input/data/proc/data_voto.rds"), habilitado_2v == 1), "voto") %>% dplyr::mutate(ins1 = NA_real_)

# Medidas en la muestra emparejada: tratados menos controles
psm_medidas <- function(md, voto) {
  t <- md$educacion_ciudadana == 1
  w <- md$weights
  m <- function(s) wmean(md$y[s], w[s])
  br <- function(s) m(s & md$origen_alto == 1) - m(s & md$origen_alto == 0)
  c(nivel = m(t) - m(!t),
    de = if (voto) NA_real_ else wsd(md$y[t], w[t]) - wsd(md$y[!t], w[!t]),
    brecha = br(t) - br(!t),
    insuf1 = if (voto) NA_real_ else wmean(md$ins1[t], w[t]) - wmean(md$ins1[!t], w[!t]))
}
# Bootstrap de pares emparejados: remuestreo de subclases
psm_boot <- function(md, voto) {
  set.seed(semilla)
  sub <- split(seq_len(nrow(md)), md$subclass, drop = TRUE)
  t(replicate(B, psm_medidas(md[unlist(sub[sample.int(length(sub), length(sub), replace = TRUE)]), ], voto)))
}

psm_res <- list()
psm_n <- list()
for (r in names(psm_datos)) {
  d <- psm_datos[[r]]
  voto <- r == "voto"
  # Con emparejamiento exacto por ola y origen social
  m_ex <- MatchIt::matchit(f_psm, data = d, method = "nearest", discard = "both", caliper = 0.01,
                           exact = ~ ola + origen_alto)
  md <- MatchIt::match.data(m_ex)
  n_trat <- table(factor(md$origen_alto[md$educacion_ciudadana == 1], levels = 0:1))
  est <- psm_medidas(md, voto)
  rep_b <- psm_boot(md, voto)
  if (min(n_trat) < 30) {
    est["brecha"] <- NA
    rep_b[, "brecha"] <- NA
  }
  # Especificación de analysis_psm.qmd, sin emparejamiento exacto: solo nivel
  m_sin <- MatchIt::matchit(f_psm, data = d, method = "nearest", discard = "both", caliper = 0.01)
  md_sin <- MatchIt::match.data(m_sin)
  est_sin <- psm_medidas(md_sin, voto)[["nivel"]]
  se_sin <- stats::sd(psm_boot(md_sin, voto)[, "nivel"])
  psm_n[[r]] <- data.frame(resultado = r, tratados_origen_bajo = as.integer(n_trat[["0"]]),
