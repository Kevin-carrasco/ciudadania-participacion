Este documento replica las regresiones de interés político de analysis.qmd y analysis_gse.qmd restringiendo la muestra a personas jóvenes: menores de 30 años en la primera sección y menores de 35 en la segunda, según edad_nac. Carga los datos procesados en preparation.qmd. Las tablas se guardan en output/tables/jovenes_*.html, y las muestras y modelos en output/models/modelos_jovenes.rds.

Al restringir la edad, el grupo de comparación queda más cerca en edad de quienes cursaron la asignatura, que tienen entre 18 y 23 años. En cada sección se estiman cinco modelos sobre la misma muestra de casos completos, todos con efectos fijos de ola: sin otros controles (1), con nivel educacional (2), con nivel educacional y edad (3), con grupo socioeconómico (4) y con grupo socioeconómico y edad (5). En estas edades muchas personas siguen estudiando, por lo que el nivel educacional puede ser afectado por el tratamiento; el grupo socioeconómico no tiene ese problema.

data_int <- readRDS("input/data/proc/data_int.rds")

# Agrupación de gse (referencia: D-E), igual que en analysis_gse.qmd
agrupar_gse <- function(x) {
  factor(dplyr::case_when(x %in% c("ABC1", "C2") ~ "ABC1-C2",
                          x == "C3" ~ "C3",
                          x %in% c("D", "E") ~ "D-E"),
         levels = c("D-E", "C3", "ABC1-C2"))
}

data_int <- data_int %>% dplyr::mutate(gse3 = agrupar_gse(gse))

# Muestra de casos completos bajo una edad máxima (exclusiva)
muestra_edad <- function(edad_limite) {
  data_int %>%
    dplyr::filter(edad_nac < edad_limite) %>%
    dplyr::select(ola, int_pol, educacion_ciudadana, educ, gse3, edad_nac) %>%
    na.omit()
}

# Los cinco modelos de cada sección
estimar_modelos <- function(d) {
  list(
    lm(int_pol ~ educacion_ciudadana + factor(ola), data = d),
    lm(int_pol ~ educacion_ciudadana + educ + factor(ola), data = d),
    lm(int_pol ~ educacion_ciudadana + educ + edad_nac + factor(ola), data = d),
    lm(int_pol ~ educacion_ciudadana + gse3 + factor(ola), data = d),
    lm(int_pol ~ educacion_ciudadana + gse3 + edad_nac + factor(ola), data = d)
  )
}

nombres_modelos <- c("1: solo EF ola", "2: + educ", "3: + educ y edad",
                     "4: + gse", "5: + gse y edad")
