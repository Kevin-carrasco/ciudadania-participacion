Presentación

Este proyecto evalúa si la asignatura de Educación Ciudadana (3° y 4° medio desde 2020) y el Plan de Formación Ciudadana (Ley 20.911, desde 2016) se asocian con el interés político y la participación electoral de las cohortes expuestas, usando las olas 77 a 95 de la Encuesta CEP.

En los resultados que siguen, educacion_ciudadana identifica a quienes tuvieron la asignatura según su fecha de nacimiento: nacidos desde el 01-abr-2003, que en edad normativa cursaron 3° medio en 2020 o después. Los casos sin fecha de nacimiento quedan fuera de los modelos. El detalle de la construcción está en el documento de preparación y los modelos en el de análisis.

Interés político

La base de interés político reúne las olas CEP 85, 88, 92, 93, 95, las únicas que incluyen la pregunta “¿Cuán interesado está Ud. en la política?”. Todos los modelos se estiman sobre los mismos 6.006 casos con información completa en las variables del análisis. La escala se invirtió para que 1 indique nada interesado y 5 muy interesado.

La base de voto reúne las olas CEP 86, 88, 89, 90, 91, 92, 93, 94, 95, que preguntan si la persona votó en la 2ª vuelta presidencial de diciembre de 2021. Organización del proyecto

La estructura del proyecto sigue el protocolo IPO (Input-Processing-Output) de reproducibilidad, desarrollado en el Laboratorio de Ciencia Social Abierta (LISA-COES). La carpeta input contiene las bases originales y los datos procesados, la carpeta processing contiene los documentos de preparación y análisis, y la carpeta output almacena tablas, figuras y modelos. Los detalles están en el archivo README.md.

El flujo de trabajo tiene dos pasos. El documento de preparación carga las bases CEP originales, revisa por ola las preguntas de participación, construye la variable educacion_ciudadana y guarda las bases agrupadas. El documento de análisis carga esas bases, estima los modelos y los guarda para esta presentación.

# Nombres legibles para los coeficientes de las tablas de regresión
renombrar <- function(m) {
  tr <- texreg::extract(m)
  nombres <- tr@coef.names
  nombres <- sub("(Intercept)", "Intercepto", nombres, fixed = TRUE)
  nombres <- gsub("educacion_ciudadana", "Educación ciudadana", nombres, fixed = TRUE)
  nombres <- gsub("edad_nac", "Edad", nombres, fixed = TRUE)
  nombres <- gsub("educ(?=\\p{Lu})", "", nombres, perl = TRUE)
  nombres <- gsub(":", " × ", nombres, fixed = TRUE)
  tr@coef.names <- nombres
  tr
}

olas <- function(d) paste(levels(droplevels(d$ola)), collapse = ", ")
